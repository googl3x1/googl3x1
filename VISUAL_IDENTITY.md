# Visual Identity Guide

## Color Palette

### Primary Colors
- **Accent Blue**: `#0066FF` - Primary action, highlights
- **Deep Indigo**: `#1a1a2e` - Primary background, text
- **Electric Purple**: `#9D4EDD` - Secondary accent, subtle highlights

### Secondary Colors
- **Mint Green**: `#00D9FF` - Success states, highlights
- **Coral Orange**: `#FF6B35` - Warnings, emphasis
- **Slate Gray**: `#4A5568` - Secondary text, borders

### Neutral Palette
- **White**: `#FFFFFF` - Primary background (light)
- **Off-White**: `#F7F9FC` - Subtle backgrounds
- **Light Gray**: `#E2E8F0` - Borders, dividers
- **Dark Gray**: `#2D3748` - Secondary text
- **Almost Black**: `#1A202C` - Primary text

## Typography

```
Font Stack: "Segoe UI", -apple-system, BlinkMacSystemFont, "Roboto", sans-serif

Headlines:    Bold 24px, letter-spacing -0.5px
Subheadings:  Semibold 16px, letter-spacing -0.25px
Body:         Regular 14px, line-height 1.6
Code/Mono:    "JetBrains Mono", monospace, 12px
```

## Component Styles

### Badges & Tags
```
Background:    #0066FF with 10% opacity
Text:          #0066FF (bold)
Padding:       4px 12px
Border-radius: 16px
Font-weight:   600
Font-size:     12px
```

### Cards
```
Background:    #FFFFFF
Border:        1px solid #E2E8F0
Border-radius: 12px
Box-shadow:    0 2px 8px rgba(0,0,0,0.08)
Padding:       24px
```

### Buttons
```
Primary:
  Background: #0066FF
  Text:       #FFFFFF
  Padding:    10px 20px
  Border-radius: 8px
  Font-weight: 600

Ghost (Secondary):
  Border:     2px solid #0066FF
  Text:       #0066FF
  Background: transparent
```

### Dividers
```
Color:  #E2E8F0
Weight: 1px
Margin: 16px 0
```

## Icon Guidelines
- Size: Use multiples of 4px (16px, 24px, 32px)
- Stroke: 2px for line icons
- Fill: Use primary colors, maintain contrast
- Spacing: 8px minimum from text

## Animation (Optional)
- Transitions: 200ms ease-out
- Hover effects: 10% opacity change or 2px elevation shift
- No motion for reduced-motion preference users

## Dark Mode Adjustments
- Background: `#1A202C`
- Text: `#F7F9FC`
- Accents: Increase saturation by 10%
- Borders: Use `#2D3748` instead of light gray
